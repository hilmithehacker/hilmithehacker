## 💡 Engineering Principles

<details>
  <summary><b>📐 1. Strict Geospatial Rigor (Zero Pseudo-Data)</b></summary>
  <br/>
  Every spatial calculation must be physically grounded:
  <ul>
    <li><b>CRS Discipline:</b> Distances in meters and areas in hectares are NEVER calculated in geographic degrees (EPSG:4326). Automatic reprojection to appropriate WGS 84 / UTM Zones (e.g. Zone 49S for Central Java) is mandatory.</li>
    <li><b>Topological Safety:</b> All administrative geometries pass through <code>native:fixgeometries</code> to eliminate self-intersections and sliver gaps before geoprocessing.</li>
    <li><b>Physical Elevation Only:</b> Slope and hydrology strictly derive from true calibrated DEMs (DEMNAS / Copernicus DEM GLO-30), never synthetic RGB brightness estimations.</li>
  </ul>
</details>

<details>
  <summary><b>⚡ 2. Zero-Delay Autonomous Execution</b></summary>
  <br/>
  Instead of passive text tutorials, software systems must execute directly:
  <ul>
    <li>PyQGIS socket clients control GUI viewports (<code>iface.zoomToActiveLayer()</code> and canvas refresh).</li>
    <li>In-memory scratch layers (<code>TEMPORARY_OUTPUT</code>) prevent disk I/O bottlenecks and Windows file locks.</li>
  </ul>
</details>
